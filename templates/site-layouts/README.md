# Шаблоны макетов сайтов

Каталог для переиспользуемых шаблонов страниц, секций и UI-каркасов.

## Доступный шаблон

- `five-ai-projects-template/` — сохранённый шаблон каталога ТЗ из источника `aiproject-dr.ru/five-ai-projects`.

## Быстрый старт

1. Скопируйте `five-ai-projects-template` в новый каталог под ваш проект.
2. Обновите контент в `docs-bundle.js` и массив проектов в `app.js`.
3. При необходимости скорректируйте стили в `styles.css`.
