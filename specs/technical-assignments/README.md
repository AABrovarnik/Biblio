# Технические задания (библиотека)

Сводные ТЗ, пригодные для повторного использования и адаптации.

## Доступные ТЗ

- `01-english-tutor.md` — AI-репетитор английского языка.
- `02-ai-sales-agent.md` — универсальный AI-продажник.
- `03-rag-consultant.md` — AI-консультант с RAG.
- `04-meeting-secretary.md` — AI-секретарь совещаний.
- `05-ai-developer-website.md` — сайт AI-разработчика с AI-аудитором бизнеса.

## Рекомендация по использованию

Перед стартом нового проекта:
1. Копируйте ближайшее по типу ТЗ.
2. Явно фиксируйте обязательные сценарии, ограничения и критерии приёмки.
3. Добавляйте секцию «Границы демо-режима» и «Контрольные ситуации».
