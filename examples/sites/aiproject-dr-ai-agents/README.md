# Aiproject DR — AI Agents

Сохранённый пример каталога AI-агентов:
- URL: https://aiproject-dr.ru/ai-agents/
- Дата импорта: 2026-11-17 (Europe/Moscow)

## Содержимое

- `source/index.html` — HTML страницы.
- `source/styles.css` — стили и визуальная система.
- `source/script.js` — логика интерфейса и фильтрации.
- `source/data.js` — 50 идей AI-агентов в структурированном формате.

## Зачем хранится в библиотеке

- как референс структуры продуктового каталога;
- как база для отбора «Идей на будущее»;
- как пример сегментации идей по B2B/B2C-блокам.
