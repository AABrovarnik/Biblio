# Aiproject DR — 5 AI Projects

Сохранённый пример сайта и ТЗ из источника:
- URL: https://aiproject-dr.ru/five-ai-projects/#projects
- Дата импорта: 2026-11-17 (Europe/Moscow)

## Содержимое

- `source/` — исходные клиентские файлы (HTML, CSS, JS, ассеты).
- `specs/` — извлечённые ТЗ в Markdown:
  - `01-english-tutor.md`
  - `02-ai-sales-agent.md`
  - `03-rag-consultant.md`
  - `04-meeting-secretary.md`
  - `05-ai-developer-website.md`

## Как использовать

1. Быстро читать/копировать ТЗ — открывайте файлы из `specs/`.
2. Изучать структуру оформления сайта — смотрите `source/app.js` и `source/styles.css`.
3. Использовать как шаблон для нового каталога ТЗ — копируйте `source/` в новый проект и меняйте массив `PROJECTS` + Markdown-документы.
