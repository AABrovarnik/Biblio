# Идеи на будущее

Раздел для хранения и приоритизации продуктовых идей, которые можно превращать в MVP.

## Формат

- `*-catalog.md` — длинные каталоги идей из внешних источников.
- `*-shortlist.md` — отобранные идеи под ближайшие спринты.
- `*-roadmap.md` — дорожные карты с приоритетами и зависимостями.

## Текущие материалы

- `ai-agents-catalog.md` — 50 идей AI-агентов из открытого каталога.
